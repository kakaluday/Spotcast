# Spotcast Website Platform

Official source repository for the Spotcast New Zealand website redevelopment.

## Project goals
- Preserve the existing Spotcast logo, typography, colours and brand voice.
- Deliver a premium, mobile-first advertising website.
- Help advertisers discover the screen network and submit campaign enquiries.
- Support venue partners and scalable inventory management.

## Project status
Planning and foundation. No live website changes have been made.

## Collaboration
Work on feature branches, open pull requests, review preview deployments and merge approved work into `main`. See [Collaboration](docs/collaboration.md).
